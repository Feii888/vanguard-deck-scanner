# Vanguard Deck Scanner

Reads Decklog deck codes from Cardfight!! Vanguard results images (tournament graphics, screenshots,
X / Twitter posts) and shows every deck, grouped by team placement and seat for team events.

Open it: https://feii888.github.io/vanguard-deck-scanner/

- **iPhone / iPad:** open the link in Safari, tap Share, then *Add to Home Screen*.
- **Android:** open the link in Chrome, then *Add to Home screen* or *Install app* in the menu.
- **Mac:** use the link, or download `Vanguard Deck Scanner for Mac.zip` from this repository.
- **Windows:** use the link, or save `index.html` and double-click it.

Images are read on your own device and are not uploaded anywhere. Deck pictures come from Decklog;
X post pictures are looked up through FxTwitter. The text reader (Tesseract.js) loads from jsDelivr.

The website copy counts visits and a few app actions (such as "scan started" or "X link used") with
[GoatCounter](https://www.goatcounter.com/), including the public address of each X post that gets scanned.
No cookies, nothing personal, and never pictures, deck codes or other links. The downloaded `index.html`
and the Mac app count nothing.
