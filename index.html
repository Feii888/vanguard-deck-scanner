Quick guide

Collect your results images first, then scan them in one go. Everything works the same on Windows and Mac; only the shortcut keys differ, and both are listed below. You're on Windows.

On a phone or tablet: open this page in Safari (iPhone, iPad) or Chrome (Android) and use Share → Add to Home Screen to get it as an app. On a Mac you can also download the Mac app.

Scan a batch of images

  1. Paste images one after another with Ctrl+V. That can be a picture, a link to an X / Twitter post (all of the post's pictures come in), or a link to a picture. You can also drag and drop files, or use Choose images. Each image shows up as a numbered thumbnail, labelled “Pasted image 1” or “@account picture 1 of 4” and so on.
  2. Arrange the list if you need to. The ← and → buttons on a thumbnail move it earlier or later, and × removes it. That order becomes Image 1, 2, 3 in the results.
  3. Pick Solo or Teams of 3 next to the Scan button. It applies to the whole batch and is remembered for next time. You can still change any single image after scanning.
  4. Press “Scan N images”, or Ctrl+Enter. The images are scanned in the order shown, and the page jumps to the first one.

Reading the results

  • 1Numbered boxes on the image match the numbered deck cards below it. Click a box to jump to its deck.
  • 1st · Seed AIn Teams of 3, decks are grouped under their placement. Seed A is the left seat, B the middle, C the right.
  • First read as 1ZNWSEThe code was corrected after a closer look. Compare it with the cropped name and code shown next to it.
  • Not found on DecklogPick one of the look-alike codes offered, or type the code from the picture into the box on the card.
  • No code read hereAn empty seat, shown in its place between the other decks. Type the code shown in its crop.
  • SnapshotClick a deck picture to enlarge it, then flip through every deck with the arrow keys.
  • Copy linksPuts every deck on the clipboard, one per line, with its placement and seed.

Compare decks side by side

  1. Tick “Compare” on each deck you want to compare; tick it again to switch it off. The deck gets a blue outline, and a Compare tab appears next to Scanner, showing how many decks are marked.
  2. Open the Compare tab: click the red hexagon symbol that appears on the right of a ticked “Compare” button, the red Compare button at the bottom of the screen, or the tab itself. The marked decks sit side by side; choose 1 to 4 per row. Click a deck to enlarge it, then use ← / → to flip through the marked decks only. “Find” jumps back to the deck in the Scanner tab.
  3. To remove decks, tick them in the Compare tab and press Unmark selected, or press Unmark all (twice, to confirm). You can also untick “Compare” on the deck card. The tab disappears when no deck is marked.

FAQ

Answers about adding images, reading results, teams and placements, and running the app on Windows or Mac.

Adding images

What happens if I paste the same image twice?

The second copy is skipped and a message tells you so.

Can I scan an image again?

Yes. An image you've already scanned is marked “scanned before as Image 2” in the tray, but it isn't blocked, in case you want to re-scan it.

Can I keep adding images while a scan is running?

Yes. New images wait in the tray for the next Scan.

Can images scan as soon as I add them, like before?

Tick “Scan right away when images are added” under the tray. It's off by default and remembered.

How do I get pictures from an X / Twitter post?

Copy the post's link (Share → Copy link, or copy it from the address bar) and paste it anywhere in the app, the code box included. All of the post's pictures go into the tray at full size, named after the account.

Which X link formats work?

Any link to a post: x.com and twitter.com, mobile links, /i/status/ links, links ending in /photo/1 or with extra bits like ?s=46 after the number, links without https://, copied hyperlinks, and FxTwitter, VxTwitter or Nitter links. Short t.co links can't be opened; copy the post's own link instead.

Pasting an X link didn't bring any pictures. Why?

The post may be deleted, from a protected account, age-restricted, or have only a video. If the lookup service is down, the app says so: then open the post, right-click a picture, choose Copy image and paste it.

How do I get a picture from another website into the tray?

Right-click the picture, choose Copy image, then paste here. A link to a picture works too, if that site allows downloads. Or take a screenshot straight to the clipboard: ⊞ Win+Shift+S on Windows, ⌃ Control+⇧ Shift+⌘ Cmd+4 on Mac. Full-size originals read best.

Results

Why does a deck say “First read as …”?

The first reading had no deck on Decklog, and a closer look found one that does. The crop next to the code lets you check it.

A code is missing or “Not found on Decklog”. What now?

Every card for a code that couldn't be confirmed has a box where you type the code from the picture and press Look up. Where a look-alike code exists, it's offered with its deck picture to pick. A seat where no code was read at all shows an empty card in its place between the other decks, with the same box, and so does a picture where nothing was read. You can also use “Rescan an area” and drag a box around the code on the image.

Why is a code shown as a choice between two decks?

Sometimes two different readings of a blurry code both exist on Decklog. Rather than guess, the app shows both with their deck pictures; pick the one that matches the picture.

Why are numbers like 13000 ignored?

Those are card power values printed on the card art. Decklog codes are 5 or 6 letters and digits, never digits only, and never contain the letters O or I.

How do I compare decks side by side?

Tick “Compare” on the deck cards you want. A Compare tab appears between Scanner and Guide & hotkeys. To get there, click the red hexagon symbol on the right of any ticked Compare button, or the red Compare button at the bottom of the screen. Decks you mark from different images and teams all collect in the same tab. Marks last until you reload the page.

How do I take decks out of the comparison?

In the Compare tab, tick the decks to remove and press Unmark selected, or press Unmark all. Unticking “Compare” on a deck card works too. Unmarking doesn't remove the deck from the Scanner tab.

What does the JP / EN switch do?

Japanese and English Decklog are separate sites with separate codes. Use EN for codes from decklog-en.bushiroad.com.

Teams and placements

How are teams and seeds worked out?

In Teams of 3, each group of three codes side by side in a row is one team. Seed A is the left seat, B the middle, C the right.

My team's decks are in separate pictures, one deck each. Does that work?

Yes. In Teams of 3, pictures that each show a single deck (deck-recipe graphics, posted as first, middle and captain) are grouped in threes in the order they sit in the tray: seats A, B and C of one team. Use the arrows in the tray if they arrive out of order.

Where do placements like “5th” come from?

From the banners above each team. Ties are kept. A team whose banner can't be read is numbered from its neighbours and marked as a guess.

A placement is wrong. Can I fix it?

Click the placement heading and type the number. Only that team changes.

Windows, Mac and privacy

Does it work on a Mac?

Yes. Use the Mac app (“Vanguard Deck Scanner for Mac.zip”), or simply open the .html file in Safari, Chrome or Edge. Shortcuts use ⌘ Cmd where Windows uses Ctrl, and ↩ Return for Enter; the guide lists both side by side.

Can I put it on my phone's Home Screen?

Yes. On iPhone or iPad, open this page in Safari, tap Share, then Add to Home Screen. On Android, open it in Chrome and choose Add to Home screen or Install app from the menu. It then opens full-screen like an app. Pick photos with Choose images, or paste pictures and links into the box at the top.

Where do I get the Mac app?

Download Vanguard Deck Scanner for Mac (zip). Unzip it, move the app to Applications and allow it once, as described below.

The Mac app says Apple can't check it for malware. Is it safe?

That message appears for every app that isn't signed with a paid Apple developer certificate. Allow it once: on macOS 15 or newer, open System Settings → Privacy & Security and click Open Anyway; on older versions, right-click the app, choose Open, then Open again. Inside the app is a short launcher script and this page, and you can read both (right-click the app → Show Package Contents). If you'd rather not approve anything, open the .html file instead: it runs inside your browser with no prompt.

Are my images uploaded anywhere?

No. Text is read inside your browser. Only the deck codes go to Decklog, to fetch the deck pictures. For an X link, the post's number goes to FxTwitter, a free public service that lists the post's pictures, and the pictures download from X's own image server. The text reader itself (about 5 MB) downloads once from jsDelivr. On the website copy, anonymous visit counts go to GoatCounter (see the next question).

Does it count visitors?

Only the website copy (feii888.github.io). It counts visits and a few actions, such as “scan started”, “X link used” or “every code found”, with GoatCounter, so its maker can see how much it gets used. For an X link, it also records which post was scanned (the post's public address, such as x.com/account/status/number). It sets no cookies and doesn't record who you are; pictures, deck codes and other links are never sent. GoatCounter only sees what any website sees: the browser, screen size, country and the page you came from. The downloaded .html file and the Mac app count nothing.

Does it need an internet connection?

Yes: for the text reader on first use, and for the deck pictures from Decklog.

How do I update the app?

Replace index.html with the new file and reload: F5 on Windows, ⌘ Cmd+R on Mac. Images on screen are cleared by a reload, so add them again.
